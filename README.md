## 🇮🇷 درباره پروژه

**برسام باغبان‌زاده**، پژوهشگر ۱۴ ساله هوش مصنوعی از رشت، ایران، پلتفرمی را خلق کرده است که مرزهای تکنولوژی و سلامت دیجیتال را جابه‌جا می‌کند. این پروژه یک وب‌سایت معمولی نیست؛ بلکه یک **سیستم عامل هوشمند تحت وب** است که شامل آزمایشگاه یادگیری فدرال، موتور استنتاج زنده TensorFlow.js، نقشه دفاع سایبری و دستیار صوتی چندزبانه است.

### ✨ ویژگی‌های کلیدی:
- 🧠 **آزمایشگاه یادگیری فدرال (FL Lab):** شبیه‌سازی زنده الگوریتم‌های FedAvg و FedProx با نمودارهای Real-time.
- ⚡ **موتور استنتاج زنده:** اجرای مدل‌های واقعی تشخیص بیماری قلبی مستقیماً در مرورگر با TensorFlow.js.
- 🛡️ **نقشه دفاع سایبری:** نمایش زنده حملات و دفاع‌های سایبری در سطح جهانی.
- 🎙️ **اسکنر بیومتریک صوتی:** تولید اثر انگشت دیجیتال از طریق تحلیل امواج صدا.
- 🤖 **دستیار هوشمند صوتی:** آواتار انگلیسی‌زبان که با افتخار از دستاوردهای برسام می‌گوید.
- 🌍 **پشتیبانی از ۸ زبان زنده:** فارسی، انگلیسی، عربی، ترکی، فرانسوی، آلمانی، اسپانیایی و چینی.
- 🎨 **۸ تم اختصاصی:** از حالت سایبری نئونی تا شفق قطبی و نیمه‌شب.
- 💻 **ترمینال تعاملی AI:** محیطی شبیه به هکرهای حرفه‌ای برای اجرای دستورات سیستمی.

## 🇬🇧 About The Project

**Barsam Baghbanzadeh**, a 14-year-old AI researcher from Rasht, Iran, has created a platform that pushes the boundaries of technology and digital health. This is not just a website; it is a **web-based intelligent operating system** featuring a Federated Learning lab, a live TensorFlow.js inference engine, a cyber defense map, and a multilingual voice assistant.

### ✨ Key Features:
- 🧠 **Federated Learning Lab:** Live simulation of FedAvg and FedProx algorithms with real-time charts.
- ⚡ **Live Inference Engine:** Running real cardiac disease prediction models directly in the browser using TensorFlow.js.
- 🛡️ **Cyber Defense Map:** Real-time visualization of global cyber attacks and defenses.
- 🎙️ **Voice Biometric Scanner:** Generating digital fingerprints through audio wave analysis.
- 🤖 **Smart Voice Assistant:** An English-speaking avatar that proudly speaks about Barsam's achievements.
- 🌍 **8 Live Languages:** Persian, English, Arabic, Turkish, French, German, Spanish, and Chinese.
- 🎨 **8 Custom Themes:** From neon cyber mode to aurora and midnight.
- 💻 **Interactive AI Terminal:** A professional hacker-like environment for executing system commands.
